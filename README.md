# Artemis 🤖

Assistente virtual para Windows controlada por voz.

## Recursos
- Comandos naturais
- Controle de mídia
- Controle de volume
- Abertura de aplicativos
- Pesquisa na internet
- Ações do Windows
- Voz em português
- Inicialização automática

## Tecnologias
- Python
- OpenAI API
- SpeechRecognition
- Edge TTS
- Pygame
- PyInstaller
